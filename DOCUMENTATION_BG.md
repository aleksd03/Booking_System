# ADBook - Система за Резервации

Уеб-базирана система за резервация на ресурси, разработена с PHP и MySQL. Системата позволява на потребителите да разглеждат и резервират различни ресурси (конферентни зали, спортни съоръжения, оборудване), докато администраторите могат да управляват ресурси, резервации и потребители.

## ✨ Характеристики

### Потребителски функции
- **Регистрация и вход**: Сигурна система за автентикация
- **Преглед на ресурси**: Виждане на всички налични ресурси с филтриране по категория
- **Създаване на резервации**: Резервиране с автоматично изчисляване на цена
- **Моите резервации**: Преглед и управление на лични резервации (предстоящи, минали, отказани)
- **Отказване на резервации**: Възможност за отказване на предстоящи резервации
- **Възстановяване на парола**: Заявка за нова парола чрез администратор

### Администраторски функции
- **Dashboard**: Преглед със статистики (общо резервации, приходи, потребители и др.)
- **Управление на ресурси**: Пълни CRUD операции за ресурси (създаване, редактиране, изтриване)
- **Управление на резервации**: Преглед на всички резервации с разширено филтриране
- **Управление на потребители**: Преглед, промяна на роли, изтриване на потребители
- **Статистики в реално време**: Проследяване на резервации, приходи и използване на системата

### Технически особености
- **Responsive дизайн**: Работи на desktop, tablet и mobile устройства
- **Валидация на форми**: Client-side и server-side валидация
- **Откриване на конфликти**: Предотвратява припокриващи се резервации
- **3-часово предизвестие**: Минимум 3 часа предварително за резервации
- **Управление на сесии**: Сигурни потребителски сесии с role-based достъп
- **Чист код**: Без inline styles, правилна MVC-подобна структура

## 🔧 Инсталация

### 1. Инсталиране на XAMPP
Изтеглете и инсталирайте XAMPP от [https://www.apachefriends.org](https://www.apachefriends.org)

### 2. Клониране на проекта
```bash
cd C:\xampp\htdocs
git clone https://github.com/YOUR_USERNAME/booking-system.git
```

### 3. Създаване на база данни
1. Стартирайте XAMPP (Apache и MySQL)
2. Отворете phpMyAdmin: `http://localhost/phpmyadmin`
3. Създайте нова база данни с име `booking_system`
4. Импортирайте SQL файла: `database_setup.sql`

### 4. Конфигуриране на връзката с базата данни
Конфигурацията е зададена в `config/database.php`:
```php
$host = 'localhost';
$username = 'root';
$password = '';
$database = 'booking_system';
```

### 5. Достъп до приложението
Отворете браузър и отидете на:
```
http://localhost/booking-system
```

## 🗄️ База данни

### Таблици

#### 1. users (Потребители)
Съхранява информация за регистрирани потребители.
```sql
- id (INT, PRIMARY KEY)
- name (VARCHAR) - Име и фамилия
- email (VARCHAR, UNIQUE) - Email адрес
- phone (VARCHAR) - Телефонен номер
- password (VARCHAR) - Хеширана парола
- role (ENUM: 'user', 'admin') - Роля
- created_at (TIMESTAMP) - Дата на създаване
```

#### 2. categories (Категории)
Категории на ресурсите.
```sql
- id (INT, PRIMARY KEY)
- name (VARCHAR) - Име на категорията
- icon (VARCHAR) - Emoji икона
- description (TEXT) - Описание
```

**Примерни категории:**
- 🏢 Конферентни зали
- ⚽ Спортни съоръжения
- 💻 Оборудване

#### 3. resources (Ресурси)
Налични ресурси за резервация.
```sql
- id (INT, PRIMARY KEY)
- category_id (INT, FOREIGN KEY)
- name (VARCHAR) - Име на ресурса
- description (TEXT) - Описание
- capacity (INT) - Капацитет (човека)
- price_per_hour (DECIMAL) - Цена на час в евро
- location (VARCHAR) - Локация
- status (ENUM: 'available', 'unavailable') - Статус
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
```

**Примерни ресурси:**
- Конферентна зала А (€45/час)
- Конферентна зала Б (€28/час)
- Тенис корт 1 (€25/час)
- Лаптоп Dell XPS (€8/час)
- Проектор Epson (€6/час)
- Фитнес зала (€12/час)

#### 4. reservations (Резервации)
Записи за направени резервации.
```sql
- id (INT, PRIMARY KEY)
- user_id (INT, FOREIGN KEY)
- resource_id (INT, FOREIGN KEY)
- start_datetime (DATETIME) - Начало на резервацията
- end_datetime (DATETIME) - Край на резервацията
- total_price (DECIMAL) - Обща цена
- status (ENUM: 'pending', 'confirmed', 'cancelled', 'completed')
- notes (TEXT) - Бележки
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
```

### Връзки между таблиците
- **users** → **reservations** (един-към-много)
- **categories** → **resources** (един-към-много)
- **resources** → **reservations** (един-към-много)

### Имплементирани мерки
1. **Password Hashing**: Използва `password_hash()` и `password_verify()`
2. **SQL Injection Protection**: Prepared statements за всички заявки
3. **XSS Protection**: `htmlspecialchars()` за всички изходни данни
4. **Session Security**: Secure session management
5. **Role-Based Access**: Различни права за users и admins
6. **Input Validation**: Client-side и server-side валидация
7. **CSRF Protection**: Session-based verification

## 📊 Бизнес логика

### Правила за резервации
1. **Минимална продължителност**: 30 минути
2. **Максимална продължителност**: 24 часа
3. **Предварително време**: Минимум 3 часа преди началото
4. **Конфликти**: Системата не позволява припокриващи се резервации
5. **Ценообразуване**: Автоматично изчисление по формулата: `часове × цена_на_час`

### Статуси на резервации
- **pending** (В очакване): Изчаква потвърждение
- **confirmed** (Потвърдена): Активна резервация
- **cancelled** (Отказана): Отказана от потребител
- **completed** (Завършена): Минала резервация
